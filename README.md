# SaaS Subscription Churn Analysis

Analysis of subscription, revenue, and churn data for a B2B SaaS company using SQL.

## Tech Stack

- DuckDB
- jupysql
- JupyterLab
- pandas, matplotlib, seaborn

## How to Run

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

Open `churn_analysis.ipynb` and run the cells.
